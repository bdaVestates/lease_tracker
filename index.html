Cash flow by quarter, in a typical year

Each lease's yearly rent and service charge is counted in the quarter its renewal rent falls due, which is the day after the lease ends (a lease ending 31 March is due in Q2). Landlord rent is what we pay landlords in that quarter each year, converted to naira. Red means we would be paying from pocket.

Expected income by property and quarter

Each lease is counted in the quarter its renewal rent falls due. This adds up to the expected income in the cash flow cards above.

Data, backup and restore

All changes save automatically to a shared database, so everyone with access sees the same figures on any device. Download the spreadsheet for a dated copy or to load into Power BI.

Replace the data from a spreadsheet. Choose a spreadsheet downloaded from this dashboard (or a tenant register in the original layout). It replaces the tenant list for everyone, and the landlord list too if the file has one. Units with the same property and unit name keep their payment records.

The backup file holds everything, including payments and lease history. Keep it somewhere private: it contains tenant contacts.
